MBFサーバーには「ギルド」という制度があります。これは、仲の良い人同士でグループを作るシステムです。ギルドを通じて、結束力が高まり、似た価値観を持つ人々が集まり、交流の幅が広がります。👍


### 👍ギルドの利点
- 似た価値観や目的を持っているプレイヤーで集まることができます。
- ギルドメンバー同士で、アイテム贈与・施設の共有ができます。
- ギルドメンバーをまとめて保護メンバーに登録できます。

### 📊ギルドの一覧
公式アプリ内のギルドランキングで、ギルドの一覧を確認できます。
また、Discordの [〔🏰〕ギルド募集](https://discord.com/channels/960062675012964352/1348873048924622889) フォーラムで、募集を確認できます。

### 🚪ギルドの参加
ギルドに入ることは必須ではありません。
多くの方が無所属でプレイされています。
仲良くなった人と新しいギルドを作ることもできますし、既存のギルドに参加することもできます。

ギルドに参加するには、ギルドマスターさんに招待コードを発行してもらう必要があります。
入ってみたいギルドが見つかったら、ギルドメンバーさんもしくはギルドマスターさんに話しかけてみてください ^^♪

### 🤝ギルドの約束
- **同時に参加可能なギルド数**: 1つまで
- **禁止事項**: ギルド間の戦争は禁止されています。
- **ギルドマスターの責任**: メンバーの管理責任があります。
- **勧誘ルール**: 過度な勧誘や無理な勧誘は禁止です。

### 🚩ギルドの結成方法
公式アプリの「ギルドを設立」ボタンから、ギルドを結成できます。
結成したギルドは、プライベートギルドとして扱われます。
規模を拡大して公開ギルドにする場合は、運営チームから認定を受ける必要があります。

| 項目 | プライベートギルド | 公開ギルド |
| :--- | :--- | :--- |
| **メンバー上限** | 最大10人まで | 無制限 |
| **ギルドランキング** | 掲載されない | 掲載される |
| **運営チームの認定** | 非公認 | 公認 |
